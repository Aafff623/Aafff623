# Temp Rules

- Put temporary project material under the appropriate `temp/` subdirectory.
- Keep raw user input unchanged under `input/` when provenance matters.
- Put research in `research/`, reports in `reports/`, and cross-session handoffs in `handoff/`.
- Put experimental scripts and temporary HTML/CSS/JS in `scripts/` or `preview/`.
- Put local credentials and configuration backups only in `secrets/`; never echo their values or copy them into tracked files.
- Do not treat a report or handoff as durable project documentation until the user explicitly promotes it.
- Do not delete or clean temp material automatically. Ask before a destructive cleanup.
