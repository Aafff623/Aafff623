# Temporary Project Workspace

`temp/` is the local work area for material that helps investigate or develop the project but does not belong in the committed product tree.

Use its subdirectories for raw input, research, experimental scripts, previews, reports, handoffs, logs, cache, and local secrets. Create a subdirectory when it is needed; do not scatter temporary files across unrelated drives or project locations.

The payload is ignored by Git. Keep `README.md` and `AGENTS.md` as the two entry points that explain the boundary.
