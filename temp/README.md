# Temporary Workspace (`temp/`)

This directory is an ignored local scratchpad for generation experiments, candidate encodes, and intermediate audit reports.

## Structure

- `preview/` — Standalone local preview files for offline review.
- `reports/` — Intermediate research logs, analysis reports, and scratch plans.
- `scripts/` — Disposable experimental scripts (long-lived production scripts belong in `scripts/`).

## Rules

- Do not commit candidate binary files or frames from this directory.
- Refer to [`temp/AGENTS.md`](./AGENTS.md) and root [`AGENTS.md`](../AGENTS.md) for full governance policies.
