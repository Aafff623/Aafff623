# Code of Conduct

This is a personal GitHub profile repository. I want this space to stay friendly, respectful, and constructive for everyone who stops by.

## My Standards

- Be respectful and inclusive in discussions.
- Avoid harassment, discrimination, or trolling.
- Keep feedback constructive.
- Respect privacy — don't share personal or sensitive information about others.

## Scope

This code of conduct applies to interactions in this repository, including issues, pull requests, discussions, and any related communication.

## Reporting

If you see something that violates this code of conduct, please contact me at [laiyif68@gmail.com](mailto:laiyif68@gmail.com).

I reserve the right to remove content or block users who violate these standards.
