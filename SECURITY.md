# Security Policy

## Reporting a Vulnerability

If you discover a security issue in any code or configuration within this repository, please report it responsibly.

**Do not open a public issue for security vulnerabilities.**

Instead, email me directly at [laiyif68@gmail.com](mailto:laiyif68@gmail.com) with:

- A description of the issue
- Steps to reproduce (if applicable)
- The potential impact
- Any suggested fix

I will review reports as soon as possible and respond within a reasonable timeframe.

## Scope

This policy applies to this repository and any associated assets, scripts, or configurations included here.

## Safe Harbor

I support responsible disclosure and will not take legal action against anyone who reports security issues in good faith.
