## ⚡ 打造 Agent 工作流

对于日常的 Agent Coding Workflow，我觉得配置全面丰富的 Harness 生态能力至关重要🤔，即完整暴露给模型的外部调用环境——MCP、Skills、Hooks、Subagent、System Prompt、全局与各专属规则，以及对接 App / 插件市场；此外将生图、视频、语音等多模态能力集成进 Harness 环境，让 Agent 自主发现与调度。最后划分任务复杂度与根据项目体量让不同模型分级接手，达成最高性价比，当前（此后不断维护记录阶段性的状态）我的工作流状态如下🥳：

- 🧭 **热点讯息 / 社媒动态：** **Grok / Gemini**（前者话题、热点、新产品居多，后者更多当做多模态工作台）；
- 🔬 **复杂研究 / 详细设计：** **Opus / Sol**（深度调研、系统架构与技术方案拆解）；
- ⚡ **核心架构 / 主力编码：** **GLM 5.3, K3, Terra..**（精细重构与长期维护）；
- 🛠️ **轻量任务 / 敏捷辅助：** 一般是一些 Flash 模型系列，如 **Gemini, GLM, DeepSeek 还有 Grok** 承接短频快的体量小的任务；
- 📑 **日常办公 / 辅助协同：** **Kimi / 豆包 / GPT**
